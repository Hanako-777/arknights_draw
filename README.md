# 奇象巡展·赛博拼豆制图工具

**ARKNIGHTS DRAW · by [Hanako](https://github.com/Hanako-777)**

将图片转换为游戏固定 40 色的 24×24 图纸，或按 1～4 张宽、1～4 行自由组合多画板大图，并提供逐格修正、PNG 预览、图纸导出、工程 JSON 和本机导出历史。

## 在线使用

[打开奇象巡展·赛博拼豆制图工具](https://hanako-777.github.io/arknights_draw/)

## 功能

- 上传、拖入或粘贴 PNG、JPG、WEBP 图片
- 拖动与缩放裁剪，支持完整显示
- 均衡、主色优先、平均色优先三种转换方式
- 24×24 网格画笔、填充、取色、区块编辑、撤销与重做
- 普通模式支持画笔、同色区域和框选三种区块选择方式，可统一上色或四向移动
- 普通模式提供与主画板同步的整体预览窗口，并可随时隐藏
- 可设置宽高的大图模式，支持 2×2、3×3、4×4 等画板布局
- 大图裁剪预览会随布局改变宽高比，并显示对应的画板分块参考线
- 大图按右下角到左上角的倒序逐张施工，全部图纸自动生成署名并打包为 ZIP
- 进入大图模式和导出图纸时提示补空白画板及保存顺序
- 与游戏内顺序一致的固定 40 色色板
- 导出 PNG 预览、带编号图纸和工程 JSON
- 普通模式和大图模式分别保存最近导出的图纸历史
- 导入自己或他人的工程 JSON 继续修改

## 隐私

所有图片处理均在当前浏览器中完成，原图不会上传到服务器。工程和导出历史只保存在用户自己的浏览器或下载文件中。

## 本地运行

直接打开 `index.html`，或在 Windows 中双击 `启动工具.cmd`。推荐使用 Microsoft Edge 或 Google Chrome。

## 使用流程

1. 上传图片并调整裁剪位置。
2. 选择转换方式、对比度和饱和度。
3. 生成 24×24 初稿。
4. 使用画笔、填充、取色、区块和颜色替换进行修正。区块工具支持选择/取消选择、全选/取消全部、统一上色和四向移动；区块到达画板边缘时不会继续越界移动。
5. 导出 PNG 预览、图纸或工程 JSON。

### 编辑快捷键

- `1` / `2` / `3` / `4`：切换画笔、填充、取色、区块工具
- 区块工具中，`Q` 切换选择与取消选择，`E` 循环切换画笔选择、同色区域和框选
- 区块工具中，`R` 使用当前色统一上色，`WASD` 或方向键移动选中区块
- 区块工具可独立关闭选区遮罩或边框；两者默认显示

需要制作大图时，点击页面右上角的“大图模式”，设置每行画板数和画板行数后生成。请按照页面显示的顺序从右下角向左上角倒着施工；若一行不足四张，完成该行后需新建并直接保存空白画板，将一行补足四张再继续下一行。导出时会按当前布局打包全部图纸。

## 更新记录

### 2026-08-10 · 96×96 大图模式

- 新增独立的大图模式页面，可将一张图片转换为 16 张 24×24 画板。
- 使用堆叠画板逐张修正，并按照 16→01、从右下角到左上角的顺序施工。
- 加入带画板间隔的总览、整套图纸 ZIP 导出、图纸署名和大图导出历史。

### 2026-08-11 · 大图布局自由设置

- 大图宽度和高度均可设置为 1～4 张画板，不再仅限于 4×4 和 96×96。
- 原图裁剪比例与分块参考线会随画板布局同步变化。
- 导出图纸会在真正换行的位置提醒补充空白画板，并新增大图模式使用说明。

### 2026-08-11 · 普通模式整体预览窗口

感谢 GitHub 用户 @LampTales（B 站：**@灯语夜阑**）提交的 [PR #1](https://github.com/Hanako-777/arknights_draw/pull/1)。

- 在普通模式的主画板左侧新增缩小的整体预览，逐格修改时会同步刷新。
- 工具栏新增“显示预览”开关，可按需要隐藏或恢复预览窗口。
- 工程文件会保存预览窗口的显示状态，重新载入后自动恢复。
- 窄屏设备会自动调整预览窗口的位置，避免挤压主画板。

### 2026-08-13 · 原始 24×24 PNG 导出

感谢 GitHub 用户 @LampTales（B 站：**@灯语夜阑**）提交的 [PR #2](https://github.com/Hanako-777/arknights_draw/pull/2)。

感谢 GitHub 用户 @LampTales（B 站：**@灯语夜阑**）提交的 [PR #3](https://github.com/Hanako-777/arknights_draw/pull/3)。

- 均衡模式新增“深色强化”和“主色强化”滑块，方便保护轮廓或减少零散过渡色。
